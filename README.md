# Velvet & Spice 🍔

A responsive restaurant menu website built with HTML, CSS, and JavaScript.

## 🌟 About the Project

Velvet & Spice is a fictional restaurant website created as a practice project to improve my front-end development skills and apply what I have learned in JavaScript.

The website allows users to browse the restaurant menu and filter dishes by category.

## ✨ Features

- Responsive restaurant menu layout
- Menu categories:
  - All
  - Main Dishes
  - Starters
  - Desserts
  - Drinks
- Dynamic menu cards generated using JavaScript
- Category filtering
- Clean and modern design
- Arabic menu content with an English interface
- Responsive layout for different screen sizes

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 📚 What I Learned

Through this project, I practiced:

- Working with arrays and objects in JavaScript
- Using forEach() to display data dynamically
- Using filter() to filter menu items
- Creating and modifying DOM elements
- Handling click events
- Using data-* attributes
- Organizing JavaScript code into functions
- Building responsive layouts with CSS Grid
- Styling and designing a complete webpage from scratch
